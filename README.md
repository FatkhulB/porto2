# Persona 3 Reload Portfolio — Fatkhul Barri

Interactive web portfolio inspired by the signature UI/UX aesthetic of **Persona 3 Reload** (Atlus). Built with pure vanilla modern web technologies for maximum performance, 60fps animations, and mobile/desktop responsiveness.

## ✨ Features
- **Persona 3 Reload Aesthetic**: High-contrast dark midnight blue, black, pure white, and vibrant cyan styling with custom cutout typography and geometric blade headers.
- **Interactive Floating Music Deck**: Integrated BGM player featuring original Persona 3 tracks, scrubber timeline, play/pause, ±10s seek controls, and track selection.
- **Project & Certificate Showcase**: Social Link-styled project inspection and verified credentials grid with live credential verification links.
- **Mobile Responsive & Landscape Lock**: Tailored layouts for desktop, tablet, and mobile with corner quick-back buttons and auto-rotate guides.
- **Seamless Browser Navigation**: Full HTML5 History API integration with hash routing, preventing unexpected page exits or `about:blank`.

## 🛠️ Tech Stack
- HTML5 & Semantic Elements
- Modern CSS3 (Variables, Clamp, Flexbox, CSS Grid, Clip-path, Hardware-accelerated Keyframes)
- Vanilla JavaScript (ES6+, Web Audio, HTML5 History API)
- Pure assets (Fonts, Video loops, SFX & Music)
